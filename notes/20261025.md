# 2026-10-25 フェーズ2a：骨組みとタイトル場面

## 決定事項（理由つき）
- 技術：方式A（HTML/CSS＋SVG → Playwright で撮影 → ffmpeg）
  - 理由：角丸カード・強調色・線画・フェードが CSS/SVG で素直に書け、見た目の調整がしやすい
  - 選ばなかった案：方式B（Pillow）は速い（約45秒）が、図やレイアウトを足すたびに座標計算のコードが増える。
    Remotion は専用ブラウザのダウンロードが必要で、この環境では動かない見込み
- フォント：Zen Maru Gothic（Medium／Bold）
  - 理由：線がやわらかく「やさしい図解」に合う。M PLUS Rounded 1c も候補。Noto Sans JP は丸みがないので外した
- 字幕のルール（ユーザー指示）：1つのメッセージ（結論）で1枚にする。同じ結論の文は途中で切らない。
  データには改行を入れず、画面幅に合わせて自動で折り返す
  - 折り返す位置は「、。）／」の後ろ、「 →」の前、漢字などに続く助詞（を は が に で も）の後ろから選ぶ。
    句読点を優先し、次に2行の長さが近いものを選ぶ
- 完成した mp4 は git にコミットする（クラウド環境が消えるため）。プレビュー（out/preview/）はコミットしない
- 動画ごとにフォルダを分ける：videos/<名前>/scenes.json

## やったこと
